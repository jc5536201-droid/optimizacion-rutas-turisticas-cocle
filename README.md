## Proyecto de tesis: Cálculo de rutas turísticas en Coclé mediante el algoritmo de Dijkstra

Este proyecto forma parte de un trabajo de graduación presentado como opción de tesis para optar por el título de Licenciado en Matemáticas en la Universidad de Panamá.

### Descripción del proyecto

El proyecto consiste en aplicar la teoría de grafos y el algoritmo de Dijkstra para calcular rutas turísticas de distancia mínima entre diferentes atractivos turísticos de la provincia de Coclé, Panamá.

La aplicación utiliza herramientas de programación en Python para representar los lugares turísticos como nodos y las conexiones entre ellos como aristas ponderadas por la distancia. A partir de esta representación, se determinan las rutas de menor distancia de acuerdo con los datos disponibles.

### Objetivos

* Aplicar el algoritmo de Dijkstra al cálculo de rutas turísticas de distancia mínima.
* Representar los atractivos turísticos de Coclé mediante un grafo.
* Desarrollar una herramienta informática en Python para apoyar la planificación de itinerarios turísticos.
* Facilitar la reproducción, revisión y mejora del procedimiento computacional por parte de otros interesados.

### Tecnologías

* **Python:** desarrollo de la aplicación y ejecución de los cálculos.
* **Teoría de grafos:** representación matemática de los lugares y sus conexiones.
* **Algoritmo de Dijkstra:** determinación de rutas de distancia mínima.
