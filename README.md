# Optimización de rutas turísticas en la provincia de Coclé, Panamá

Este proyecto implementa el algoritmo de Dijkstra para calcular rutas óptimas entre atractivos turísticos de la provincia de Coclé, Panamá.

## Características

* Modelado del problema mediante un grafo con nodos y aristas.
* Inclusión de 29 atractivos turísticos.
* Cálculo de rutas óptimas utilizando la distancia como criterio principal.
* Consulta complementaria de tiempo estimado y costo.
* Generación de representaciones gráficas y evaluaciones computacionales.

## Tecnologías

* Python
* NetworkX
* Matplotlib
* OpenPyXL

## Ejecución

Ejecutar el archivo principal de Python desde una terminal con las dependencias instaladas.

```bash
pip install networkx matplotlib openpyxl
python optimizacion_rutas_cocle.py
```

**Nota metodológica:** las distancias, los tiempos y los costos deben interpretarse de acuerdo con los datos y las validaciones documentados en el código.
